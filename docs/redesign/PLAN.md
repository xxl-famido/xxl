# woofia_sim 디자인·UX 전면 개편 계획 (v2.0)

작성 2026-09-28. 근거: 라이브 사이트 실측 스크린샷(`tools/redesign/shots/`), `dashboard/style.css` 토큰 인벤토리, 모션그래픽 리서치(`../../../motion_graphics/RESEARCH.md`).

## 확정된 방향 (사용자 결정 2026-09-28)
- **기조**: 심플함. 대기업 제품 수준. **"AI가 만든 것처럼 보이지 않을 것"이 최우선 기준**
- **테마**: 라이트 기본 + 다크 지원 (시맨틱 토큰으로 양쪽 매핑)
- **모션**: 절제형 — 상태 전환(버튼·토글·슬롯 배치·결과 등장·숫자 롤업)에만 150–400ms. 장식 모션 없음. `prefers-reduced-motion` 준수
- **레퍼런스**: 특정 브랜드 지정 없음 → Apple HIG · Material 3 · Linear/Stripe · Toss 를 균형 있게 참고
- **구조**: 현재 정보 구조(편성 → 설정 → 결과) 유지. 시각 언어·위계·컴포넌트·모션을 교체
- **서브에이전트**: Opus 5.5, 로컬 실행만
- **작업 공간 분리(2026-09-28 사용자 지시)**: 개편본은 `dashboard_v2/` + `server_v2.py`(**포트 8778**)에서 별도로 만든다. 기존 `dashboard/` + `server.py`(8777)는 손대지 않는다. v2 서버는 API/`data/`를 server.py Handler로 위임(엔진 공유)하고, `icons/`·`guide/`·`*.json`·이미지만 dashboard/로 폴백(html/css/js는 폴백 없음). 실행 `시뮬레이터 v2 실행.bat`. 라이브 전환은 7단계에서 deploy.yml의 복사 대상을 바꿀 때 결정

## 브랜드·이미지 자산 전략 (사용자 결정 2026-09-28)
- **시뮬레이터 고유 아이덴티티**: 게임 타이틀 로고는 *게임의* 로고이지 이 사이트의 로고가 아니다. 사이트 색·컨셉을 먼저 가장 좋은 방향으로 정하고, **로고는 그 컨셉에 맞춰 따로 만든다**. 팔레트를 게임 로고 색에서 뽑지 않는다
- **순서**: 1단계에서 색·컨셉 확정 → 그 토큰으로 사이트 전용 로고(워드마크+심볼, SVG) 제작 → 심볼을 레이어 스프라이트로 만들어 첫 로드 인트로(1회)·결과 등장 앵커 모션에 사용
- **게임 로고**(`docs/redesign/assets/title_logo_steamgriddb.png`, 480×365 RGBA)는 참고·출처 표기용으로만 보관. UI에 브랜드로 쓰지 않는다
- **이미지 생성**: 로컬 Codex CLI(0.154.0, `codex exec -i <파일>`)로 필요 시 생성·정제. 용도 = 로고 심볼 탐색 초안, 빈 상태 삽화, 가이드 삽화. 아이콘은 생성하지 않고 SVG 세트(Lucide/Phosphor 등). 생성물은 정적 그림 하나가 아니라 **스프라이트(부품·프레임)로 쪼개 모션에 쓰는** 것을 기본으로. 사용 여부·범위는 판단에 맡김(사용자 위임)
- **캐릭터 아이콘**: 기존 `dashboard/icons/*.png`(46개) 그대로. 프레임만 중립화
