# v1 기존 사용자 인지 워크스루 — 방탈출 제단용 필살기 설정 중심

작성 2026-09-28. 대상: v1(http://localhost:8777/, 라이브 v1.8.5와 같은 소스)을 써 온 사용자가 v2(http://localhost:8778/)를 처음 여는 상황.
방법: 인지 워크스루(과업마다 "사용자가 무엇을 찾을까 → 그게 보이나 → 누르면 기대대로 되나 → 결과를 알아볼 수 있나" 4문항) + 실제 마우스 클릭 계측.
계측 스크립트 `tools/redesign/wt_v2.js`(과업마다 새 브라우저 컨텍스트, 1440×900, Chrome headless), 원자료 `tools/redesign/shots/walkthrough/wt_log*.json`. v1 기준 수치는 `ACTION_SETTINGS_UX.md` §2(S1~S9 실측)를 그대로 가져왔고, 없는 것은 **추정**으로 표시합니다.
소스·서버는 건드리지 않았습니다(스크린샷·로그만 생성).

심각도: **막힘**(기존 지식으로는 끝낼 수 없거나, 틀린 결과를 모른 채 받음) · **헤맴**(끝내지만 첫 시도는 빗나감) · **어색함**(끝내지만 용어·모양이 낯설어 멈칫).

## 2. 과업별 워크스루

**수정안**
- 아코디언 제목에 옛 이름을 한시적으로 병기: `cond.altar.title` = "방탈출 제단" 유지 + 요약 앞 보조 라벨 `cond.altar.v1` = "(구 길드 제단)". 첫 방문 30일 또는 3회 실행 뒤 숨김(`ui` 상태에 `seenV1Hints` 추가, `core/store.js`).
- 시트 머리에 층 바로가기 칩 `1층 · 2층 · 3층`(`altar.js` render의 `head` 옆, 키 `altar.floor.jump`="{0}층으로")을 둬서 2층이 첫 화면에서 보이게.
- 아코디언 안 스위치 아래 힌트 `cond.altar.hint`를 "켜면 층마다 별의 제단·달의 제단 점등 여부를 지정합니다. 같은 스위치가 시트 위에도 있습니다."로 바꿔 이중 스위치 의문 해소.

### T2. 확률 CD 감소 제단(1012/1013)이 켜진 상태에서 전원을 '준비되면 바로'로

| 항목 | 내용 |
|---|---|
| v1 경로 | 제단 켬 → '행동 고급 설정' → 궁극기 사용 방식 탭 → 경고 박스 '모두 준비되면 바로' = **7**, 전환 4 (S6) |
| 기대 경로 | 원인을 켠 곳(제단)에서 대응도 할 수 있으리라 보고 제단 시트를 엶 → 경고 박스를 읽음 → "‘준비되면 바로’를 … 켭니다" → **버튼이 없음** → 닫고 '행동 고급 설정'을 찾음 → 없음 |
| 실제 경로 | 행동 계획 › 실행 미리보기 위 안내의 '전원 준비되면 바로'(1). 안내는 문서 y≈1366(1440×900 첫 화면 밖), 미리보기 그림 바로 위 |
| 계측 | 제단 시트 경유 4클릭(아코디언 · 시트 열기 · 닫기 · 버튼). 결과 5명 모두 asap 확인 |
| 첫 시도 | 헤맴 — 제단 시트가 막다른 길 |
| 걸린 곳 | ① 제단 시트 경고(`adv.cd.proc.warn`)는 행동만 지시하고 버튼·링크가 없음(v1 F05가 그대로 남음). ② 버튼 문구 '전원 준비되면 바로'는 좋지만, 토스트 `plan.pv.proc.asap.done`="전원 준비되면 바로로 변경됨"은 **필살기를 아껴 두는 맞추는 동료를 제외**하는데(`store.js` ultAll L594-595) "전원"이라고 말함 |
| 심각도 | 헤맴 |
| 스크린샷 | `T2_1_altar_sheet_procwarn.png` · `T2_2_preview_procnote.png` · `T2_3_after_asap.png` |

**수정안**
- `ui/altar.js` render의 `procNote`에 미리보기 안내와 같은 버튼 2개를 넣기: `plan.pv.proc.asap`(전원 준비되면 바로) · `adv.cd.assist.all`(모두 성공 가정 켜기) → `store.plan.ultAll(...)` + 되돌리기 토스트. 그 옆에 링크 버튼 `altar.goPlan`="행동 계획에서 확인" → 시트 닫고 `#app-plan` 미리보기로 스크롤.

### 3-2 레이아웃: 행동 설정이 첫 화면 밖

1440×900에서 행동 계획은 y≈806에서 시작합니다(`v2_00_first_view.png`). v1은 오른쪽 열 '전투 설정' 아래에 우선순위와 '행동 고급 설정'이 있었습니다(`v1_00_first_view.png`). v2 오른쪽 열에는 전투 조건만 있고, 행동 계획이 아래에 있다는 표시가 없습니다(모바일 점프 칩 "행동"은 데스크톱에서 안 보임 — **추정**, 1440 캡처에 없음).

### 3-3 첫 방문 다리 — "v1의 ○○은 여기"

- 수정안: 행동 계획 패널 머리 아래에 닫을 수 있는 카드 1장(`plan.v1map.*`, `ui/plan.js build()`), v1 저장 흔적이 있을 때만:
  - "행동 고급 설정은 이 패널로 옮겼습니다: 궁극기 사용 방식 → ① 각 행의 필살기 방식 · 연동 → ③ 필살기 연동 · 턴별 타임라인 → 맨 아래 완전 수동 · 특정 턴만 다르게 → ② 예외 턴 · 캐릭터 창 턴별 계획 → ① 행에서 ‘직접 지정’"
