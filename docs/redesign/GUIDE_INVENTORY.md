**슬롯 차이 칩**(최대 육성과 다를 때만, 순서 고정, 2개까지 표시 + `+{n}` 칩(title = 나머지)): `★{n}`(스타<5) · `Lv{n}`(<60) · `도장 없음`(도장 잠금해제 꺼짐) · `적합도 {n}`(<5, 희귀도 3·4) · `스킬 조정`(열린 스킬 중 Lv<10) · `제련 +{n}`(도장 제련 켬). 육성 설정 사용이 꺼져 있으면 제련 외 칩 없음. 전체 목록은 슬롯 aria-label 에 이어짐.

## 3. 동료 육성 창 (`grow.js`)

열기: 슬롯 초상 클릭(`#app-team .slots > .slot:nth-child(N) .slot-btn`). 시트 `#app-sheets .sheet`(sheet-lg), 제목 = 동료 전체 이름. 변경은 즉시 반영(슬라이더는 놓을 때), 별도 저장 없음. 창이 열린 채 그 자리 동료가 바뀌면 자동으로 닫힘.

셀렉터: 머리 `#app-sheets .grow-head` · 왼쪽 열(육성+제련) `#app-sheets .grow-col:first-child` · 제련 `#app-sheets .grow-col:first-child .grow-sec:nth-child(2)` · 스킬 `#app-sheets .grow-skills`.

**머리**: 초상 · 태그(속성 · 포지션 · `{n}번`) · `ATK` / `HP` 값(도장 제련 켜면 작은 글씨 `제련 +{n}` 가산) · `최대 육성 대비 {n}%`(ATK 기준, 제련 제외) · 버튼 `행동 계획에서 보기`(창 닫고 행동 계획의 그 동료 행으로 스크롤 + 1초 강조; 고급 설정 사용 중이면 고급 설정 창을 엶; 팀 비교 범위 등 행동 계획 패널이 없으면 숨김).

**육성** 섹션(`육성` + 스위치 `육성 설정 사용`, 기본 꺼짐)
- 꺼짐: `끄면 최대 육성(Lv60 · 스타5 · 적합도5 · 전 스킬 10 · 도장 잠금해제) 기준으로 계산합니다.` — 필드 숨김, 스킬은 `Lv10` 글자만.
- 켜짐: 필드(숫자 입력 + 슬라이더 + `/ 최대`):
  - `레벨` 1–60(기본 60)
  - `스타` 0–5(기본 5). 낮추면 진화 단계 상한도 줄어듦
  - `진화 단계` 0–(스타+1)×5−1 (스타 2 → 0–14). ★5면 비활성 + `★5는 더 밟을 단계가 없음`
  - `적합도` 0–5(기본 5). 희귀도 3·4 외에는 비활성 + `이 등급은 적합도 보정 없음`(현 데이터는 전원 3·4)
  - 스위치 `도장 잠금해제`(기본 켬) + 안내 `도장 필살기로 나갑니다` / `일반 필살기로 나갑니다`. 스타<3이면 비활성 + `3스타부터 도장 잠금해제 가능`. 육성 설정이 꺼져 있으면 조작 불가(항상 잠금해제로 계산).

**도장 제련** 섹션: 스위치 `도장 제련`(기본 꺼짐) · `제련 한도 {n} · ATK+HP 합계`(동료별 한도, 기본 20,000) · `ATK` / `HP` 0–한도, 100 단위. 한쪽을 움직이면 다른 쪽 = 한도 − 값. 켤 때 초기값 ATK 0 / HP 한도.

**스킬 레벨** 섹션(`스킬 레벨`): 행 = `보통 공격` · `필살기`(도장 잠금해제면 `도장 필살기`, 아이콘 Rune) · `패시브 1`~`패시브 5`. 각 행: 아이콘 · 칸 이름 · 스킬 이름 · (필살기) `CD {n}턴` · 현재 레벨의 설명문 · 오른쪽 조작.
- 조작: 육성 설정 켜짐 + 열린 칸 = 슬라이더 1–10(필살기 행은 일반·도장 필살기에 같은 레벨), 꺼짐 = `Lv{n}` 표시.
- 스타별 해금(모든 희귀도 동일): 패시브 1·2는 항상 해금, 패시브 3/4/5 = 스타 3/4/5 필요(잠김 행: 자물쇠 + `스타 {n} 해금`, 설명 숨김). 패시브 2는 스타<2면 `스타 2부터 레벨업`(1레벨 고정, 제목에 `Lv1`). 도장 필살기 = 스타 3.
- 설명 로딩 중 `스킬 로딩…`, 실패 `스킬 정보를 불러오지 못했습니다`.

**하단**: `기본값 복원`(육성·도장·제련을 최대 육성으로; 이미 기본이면 비활성) → 토스트 `최대 육성으로 되돌렸습니다` + `되돌리기`.

그림: `grow_sheet_default`, `grow_head`, `grow_skills`, `grow_spec_on`, `grow_skills_star2`, `grow_seal`.
재현: 시트 연 뒤 `document.querySelector('#app-sheets [data-k="use"] input').click()`(육성 켬), 스타 입력 `[data-k="evo"] input.num-in` 값 변경 + change 이벤트, 제련 `[data-k="seal"] input`.

## 5. 행동 계획 패널 (`plan.js` main 모양)

셀렉터: 패널 `#app-plan` · ① `#app-plan .acc.steps > details:nth-child(1)` · ② `…:nth-child(2)` · 미리보기 `#app-plan .preview` · 진입 버튼 `#app-plan > .adv-enter` · 행 `#app-plan ol.prio > li[data-pos="N"]`(N = 슬롯 번호).

머리: `행동 계획` + `초기화 ▾`(aria `행동 계획 초기화 범위`).

### ① 순서와 필살기 (아코디언, 기본 펼침; 요약 = 행동 순서 이름 `A → B → …`; 기본값과 다르면 변경 표식)

### ① 순서와 필살기 (ⓘ = 방식 설명)
ⓘ: `필살기 방식: 자동은 역할 기본 리듬(놓친 필살기는 준비되는 대로), 정해진 턴만은 기본 턴·고정 칸에서만(그 턴에 준비 안 됐으면 건너뜀), 준비되면 바로는 쿨타임이 돌면 즉시. 고정하지 않은 칸은 이 방식대로 채웁니다.`
- 행: 순번 · 초상 · 이름(연동 칩) · 방식 select 3택 `자동 · {턴}` / `정해진 턴만` / `준비되면 바로` · ▲▼/끌기. **창의 ①에는 직접 지정 턴 칸·욱영 체크가 없음**(칸 고정은 ④, 욱영은 ③).
- 둘째 줄 체크(필요할 때만 보임 — 기본 상태 행은 한 줄):
  - `성공 가정`(= 확률 CD 감소 항상 성공): 제단 확률 CD 감소가 켜져 있고 전투당 1회 필살 동료가 아니며 방식이 준비되면 바로가 아닐 때 유효. title `확률로 쿨타임이 줄어드는 효과를 굴리지 않고, 필살기 턴에 필요한 만큼만 성공한 것으로 계산합니다. 자동·정해진 턴만이면 첫 필살기가 당겨지고(CD 3턴 → 3·6·9턴, CD 2턴 → 2턴부터), 쿨타임이 안 돌아온 턴에도 필살기를 고정할 수 있습니다. 결과 머리말에 이 흐름의 재현 확률이 표시됩니다.` 효과 없으면 흐림+사유: 제단 꺼짐 `확률 CD 감소 제단(1012·1013)이 꺼져 있어 효과 없음` / 전투당 1회 `전투당 1회 필살기라 확률 CD 감소 대상이 아님` / 준비되면 바로 `'준비되면 바로'는 … 자동이나 정해진 턴만으로 바꿉니다.`(비활성). 임부언이 추가 행동을 주는 1번 자리 + 고정 칸 없음이면 추가 사유(첫 필살기를 당기지 않음).
  - `방어 턴 유지`(기본 켬): 준비되면 바로 동료·연동 따라가는 동료에만 효과. title `'준비되면 바로'·따라가는 동료: 고정한 방어 칸은 필살기가 준비돼도 방어합니다. 끄면 필살기가 준비된 방어 칸에서 필살기를 씁니다.` 효과 없는데 꺼져 있으면 흐림 + `자동·정해진 턴만은 고정한 방어 칸을 항상 지킵니다 · …`.
- 이태호 안내(④에 칸이 없을 때): `④에서 이 동료 줄에 칸을 하나 이상 고정하면 임부언에게 받은 추가 행동을 턴마다 정할 수 있습니다.`

- 실행 줄: 상태(`두 팀 재실행 중…` / `바뀐 내용이 있습니다. 비교하기로 다시 계산합니다` / 오류) + `비교하기`. 기록 선택 외 편집은 대기 상태 → `비교하기`로 재계산. 반복 횟수 = 각 기록 값(빈 팀 50).
- 결과 머리 A/B: 팀 이름들 · 총 데미지(중앙값) · 이긴 쪽 `+{p}%` · `총 데미지 · {runs}회 중앙값 · 확률 범위 {min} ~ {max}` · 막대. 차이 문장 `{side}팀이 {pct}% 높음 (+{v})` / `동일`.

- 팀별 도구: `행동 계획 편집`(그 팀 사본으로 고급 설정 창을 엶 — 제목 `행동 계획 · A`, 사용 스위치 없이 항상 켜짐, ①~④ 동일. 닫으면 비교 시트로 돌아와 대기 상태) · `행동 순서`(인라인 패널: ▲▼ 순서, `특정 턴 순서 {n}개는 기록 그대로 적용됩니다`, `행동 순서 기본값으로`; 모든 턴이 잠긴 기록이면 비활성 + 안내).
