# XXL WOOFIA 공식 용어집 (시뮬레이터 UI 카피 기준)

작성 2026-09-28. 목적: 사이트 문구를 게임 공식 한국어 표기로 통일하기 위한 기준표. 짝 문서 `COPY_AUDIT.md`.

## 출처와 신뢰도

## 3. 표기 규칙

1. 공식 표기가 있으면 그대로 쓴다(띄어쓰기 포함: "보통 공격", "필살기 CD", "도장 잠금해제", "나무속성"). 사이트가 붙여 쓴 "보통공격·기초ATK·최대HP·주는딜" 은 공식대로 띄운다("기초 ATK", "최대 HP").
2. 한 개념 = 한 표기. 약칭은 1~2자 셀(타임라인 칸·범례)에서만: 평타 / 필살 / 방어.
3. 속어 금지: 궁, 궁극기, 쿨, 딜, 뎀, 힐, 스택, 풀육성, 딸피, 막타, 입질.
4. 개발 용어 금지: 결정론, 표본, 앵커, 파싱, 모델링, 게이트, 채널.
5. 영어 번역(en)도 한 표기로: 현재 EXACT 사전은 `EX Skill`, app.js 인라인 사전은 `ultimate` 를 써서 영어에서도 두 표기가 섞여 있음. SH 영어 데이터는 `EX Skill` (`Immune to EX Skill CD changes`).
