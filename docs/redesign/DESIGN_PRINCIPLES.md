# woofia_sim v2 디자인 원칙 (1페이지)

근거: `RESEARCH.md` §2·§5. 토큰: `dashboard_v2/tokens.css`(생성기 `tools/redesign/gen_tokens.py`, 대비 `TOKENS_CONTRAST.md`). 이 문서의 규칙과 체크리스트를 통과하지 못하면 다음 단계로 넘기지 않는다.

## 컨셉 "갤러리"
캐릭터 일러스트 44장이 주인공이다. UI는 약간 따뜻한 중립색 벽이고, 색은 세 곳에만 있다 — **강조색 1개**(상호작용·선택), **상태색 3개**(위험·성공·경고), **속성 표식**(8px 점·16px 아이콘). 그 외에는 회색과 타이포로 위계를 만든다.

## 규칙
1. **색** — hex 직접 사용 금지, 토큰만. 그라디언트·글로우·컬러 그림자·backdrop-blur 0. 속성색으로 배경·보더·텍스트를 칠하지 않는다. 선택 상태는 속성과 무관하게 `accent-solid` 2px 링.
2. **표면** — 패널은 `bg-surface` + `border-default` 1px, 그림자 없음. 그림자는 드롭다운(`shadow-md`)·모달(`shadow-lg`)에만. 표면 안에 보더 박스를 다시 넣지 않는다(중첩 0). 그룹 구분은 간격(그룹 간 ≥ 그룹 내 ×2) → 구분선 → 박스 순.
3. **타이포** — Pretendard Variable, 굵기 400/500/600, 크기 12/13/14/16/20/28 여섯 개. 수치는 `tabular-nums`. 20px 이상 자간 −0.01em, 28px −0.02em. 라벨 = `text-secondary` 13/500, 값 = `text-primary` 14/600.
4. **간격·라운드** — 4px 단위. 컨트롤 안쪽 8×12, 필드 간 12, 그룹 간 24~32, 패널 패딩 20, 페이지 여백 24. 라운드는 4(칩·체크·세그먼트 썸)/6(버튼·입력)/10(패널·모달·타일)/full(토글·아바타). 중첩 시 안쪽 = 바깥 − 패딩.
5. **컨트롤** — 버튼 4계층(primary 1개/화면, secondary, ghost, danger) × 크기 sm 28/md 32/lg 40. 세그먼트 5개 이하·등폭. 슬라이더 옆 직접 입력. 토글 input은 시각적 숨김(`display:none` 금지). 터치 타깃 44px(모바일). 포커스 링 `--focus-ring` 전역.
6. **위계·공개** — 라벨만 보이고 설명은 ⓘ 툴팁/펼침. 공개 단계 2단계 이하. 설정 섹션은 접힌 헤더에 현재 값 요약. **기본값에서 바뀐 것만** 표식(6px 점)과 "초기화". 기본값 상태의 화면은 조용하다.
7. **아이콘** — Lucide SVG 단일 세트(스트로크 1.5px, 16/20px). 이모지 0. 섹션 제목 앞 장식 아이콘 0. 아이콘은 기능 식별용으로만, 텍스트 없는 아이콘 버튼은 `aria-label` 필수.
8. **모션** — `dur-instant`(hover)·`fast`(토글·세그먼트)·`base`(펼침·드롭다운)·`slow`(모달·시트 등장, 퇴장은 base). 이징은 standard/enter/exit 셋. transform은 위치 이동(≤8px)·불투명도만. scale·bounce·overshoot·무한 펄스·hover translateY 금지. `transition: all` 금지(속성 지정). reduced-motion에서는 이동 제거·페이드만. 로고 스프라이트 인트로는 첫 로드 1회, 600ms 이내, 세션 저장으로 재생 억제.
9. **카피** — 구체 동사+명사("편성 저장", "50회 평균"). 친근체("~해요")·이모지·"마우스를 올려"·em dash 남발 금지. 단위는 값보다 한 단계 약한 색.
10. **접근성** — 텍스트 4.5:1, UI 3:1을 라이트·다크 따로 계산(생성기가 검증). 모든 클릭 요소는 `button`/`a` 또는 role+tabindex+키 처리. 빈 상태·에러 상태는 문장 1줄 + 행동 1개.
