# 2단계 목업 설계 계획

## 주제·사용자·역할
- 주제: XXL WOOFIA 전투 데미지 시뮬레이터. 턴제 전투에서 5인 편성의 궁극기 사이클이 총 피해를 결정한다.
- 사용자: 반복 사용하는 게임 유저(모바일 비중 높음). 편성 1~2명 바꿔 재실행하고 수치를 비교한다.
- 페이지의 일: 편성 → 조건 → 실행 → 숫자 읽기 → 비교. 첫 화면에서 실행까지 한 스크린.

## 토큰 (tokens.css 확정값)
canvas `#f8f6f4` · surface `#ffffff` · text `#1c1a18` · secondary `#4d4b49` · border `#d3d0cd` · accent cobalt `#1a73d5` (후보 azure `#0278b6`, indigo-less `#456cd7`는 목업 상단 스와치로 병기)

## 타이포
Pretendard Variable 한 가족. 표시용 28/600 tabular(결과 수치), 제목 16/600, 본문 14/400, 라벨 13/500, 캡션 12/500. 굵기 3개.

## 원칙(이 페이지를 고유하게 만드는 것)
1. **기억점은 30턴 스트립**이다. 큰 숫자 하나가 아니라, 어느 턴에 궁이 터지는지 보이는 리듬이 이 게임의 본질이다. 나머지는 조용하게.
2. 요약 헤더는 "A · B · C" 가운뎃점 나열이 아니라 **라벨-값 쌍**(라벨 tertiary 12, 값 secondary 13)으로 표처럼 정렬한다.
3. 초상화가 색을 담당한다. UI는 회색과 파랑 하나.
4. 첫 로드 모션은 없다(로고 스프라이트 인트로는 로고 제작 후 5단계에서 검토). 모션은 사용자 행동에만 답한다.

## 기본값 점검(생성물 티 제거)
- 크림+세리프+테라코타 조합 아님(근백색 따뜻한 캔버스 + 산세리프 + 파랑). ✓
- 카드 킷 아님: 패널 2개(편성·조건)만 표면이고 결과는 캔버스 위에 직접 놓는다. 같은 카드 반복 없음. ✓
- 전부 대문자 눈썹 라벨·중점 메타 문자열·"→" 버튼 텍스트 없음. ✓
- 상단바 아이콘 버튼은 텍스트 라벨과 함께(아이콘만 있는 버튼은 ≡ 하나).
